# Portfolio et projet — Anas Barakat

Ce dossier regroupe le portfolio, l'application pédagogique Labo Pharmacie et les documents de candidature sélectionnés.

## Contenu

- `index.html`, `style.css`, `script.js` : portfolio personnel.
- `mon projet labo pharmacie/` : application de gestion de production pharmaceutique.
- `CV_AnasBarakat.pdf` : aperçu PDF lié depuis le portfolio.
- `CV_AnasBarakat.docx` : CV téléchargeable depuis le portfolio.
- `Lettre_motivation_Anas_Barakat.pdf` et `.docx` : lettre de motivation.

## Vérification locale

Ouvrez `index.html` dans un navigateur moderne. Vérifiez le menu, les liens de CV, la démonstration du projet et la mise en page mobile. Aucune étape de compilation n'est nécessaire. Bootstrap est chargé depuis jsDelivr, donc une connexion Internet est nécessaire pour ses styles et son menu responsive.

L'application Labo Pharmacie est accessible depuis la section « Mes projets ». Ses données de démonstration sont sauvegardées dans le stockage local du navigateur.

## Préparation à Vercel

Le dossier racine à publier est ce dossier, celui qui contient `index.html`. Il s'agit d'un site statique : aucun framework, commande de build ou installation de dépendances n'est nécessaire. Avec Vercel CLI, lancez le déploiement depuis ce dossier et gardez le répertoire de sortie à la racine (`.`).

Les fichiers ne sont pas envoyés à GitHub dans le cadre de cette préparation. Pour déployer sur Vercel sans GitHub, ouvrez un terminal dans ce dossier et utilisez la Vercel CLI avec votre compte Vercel.

Le formulaire de contact prépare un e-mail avec `mailto:` ; il n'envoie pas les messages à un serveur.

## Confidentialité

Les CV et la lettre de motivation contenus ici sont des documents personnels. Ne les rendez publics qu'en connaissance de cause : tout fichier inclus dans un site déployé peut être accessible à ses visiteurs.
